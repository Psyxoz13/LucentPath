# ASWF OpenPBR 1.1.1 Source Map

Each material in this Unity collection was reset to the OpenPBR Surface v1.1.1 defaults, then populated from the official ASWF `examples/open_pbr_*.mtlx` source listed below. Some collection presets have no exact one-to-one ASWF example; those use the closest official example plus only documented OpenPBR layer controls such as coat, fuzz, emission, thin-film, or thin-walled geometry.
